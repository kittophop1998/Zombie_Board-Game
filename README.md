# 🧟 Zombie Card Game

เกมการ์ดซอมบี้ที่เล่นผ่าน Local Network โดยใช้ WebSocket เพื่อการเล่นแบบเรียลไทม์

## ✨ คุณสมบัติ

- 🎮 เล่นผ่าน Local Network ได้หลายคน
- 🔄 เรียลไทม์ด้วย Socket.io
- 🎨 UI สวยงามทันสมัยด้วย Material-UI
- 🃏 ระบบไพ่พิเศษ (ซอมบี้, ปืนลูกซอง, วัคซีน)
- 👥 แบ่งทีมอัตโนมัติ
- ⚔️ ระบบแบทเทิลแบบตัวต่อตัว

## 🎯 กติกาเกม

### การเริ่มเกม
1. สร้างห้องเกมและแชร์รหัสห้องให้เพื่อน
2. ผู้เล่นเข้าร่วมห้องด้วยรหัสห้อง
3. เมื่อทุกคนพร้อม กดปุ่ม "พร้อมเล่น"
4. เกมจะเริ่มเมื่อทุกคนพร้อม

### ไพ่ในเกม
- **ไพ่ตัวเลข** (1-13): ไพ่ 4 ดอก (♥ ♦ ♣ ♠) ใช้สำหรับแบทเทิล
- **ไพ่ซอมบี้**: แพร่เชื้อให้ผู้แพ้ (ต้องลงในกระดาน battle จึงจะแพร่เชื้อได้)
- **ไพ่ปืนลูกซอง**: กำจัดซอมบี้ได้ (ทุกคนได้ 1 ใบ สามารถยึดได้สูงสุด 3 ใบ)
- **ไพ่วัคซีน**: เปลี่ยนซอมบี้กลับเป็นมนุษย์ (ห้ามใช้กับตัวเอง)

### วิธีเล่น
1. ผู้เล่นแต่ละคนได้รับไพ่ 7 ใบ + ไพ่พิเศษ
2. เลือกผู้เล่นคนอื่นเพื่อเริ่มแบทเทิล
3. วางไพ่ดอกเดียวกันได้ไม่เกิน 3 ใบ (รวมไพ่พิเศษ เช่น ปืน, ซอมบี้)
4. ผู้ที่มีแต้มสูงกว่าชนะ
5. ผู้ชนะได้รับไพ่หนึ่งใบจากไพ่ที่ผู้แพ้วางในกระดาน battle

### กติกาไพ่พิเศษ

#### 🧟 ไพ่ซอมบี้
- ซอมบี้แพร่เชื้อได้ต่อเมื่อ**ลงไพ่ซอมบี้ในกระดาน battle**เท่านั้น (อยู่บนมือแพร่ไม่ได้)
- **แต้มสูงกว่า**: แพร่เชื้อสำเร็จ ผู้แพ้กลายเป็นซอมบี้และได้ไพ่ซอมบี้เพิ่ม
- **แต้มน้อยกว่า**: แพร่เชื้อไม่สำเร็จและเปิดเผยตัวตนทันทีว่าเป็นซอมบี้

#### 🔫 ไพ่ปืนลูกซอง

**มนุษย์ใช้ปืน vs มนุษย์:**
- **แต้มสูงกว่า**: ฝั่งตรงข้ามถูกยิงตาย (ถูกกำจัด)
- **แต้มน้อยกว่า**: ผู้เล่นฝั่งตรงข้ามสามารถเลือกได้ว่า
  1. ยึดปืนมาใช้เอง (เก็บได้สูงสุด 3 ใบ)
  2. ใช้ปืนยิงฝั่งตรงข้ามให้ตาย

**มนุษย์ใช้ปืน vs ซอมบี้:**
- **แต้มสูงกว่า**: ซอมบี้ถูกยิงตาย (ไม่ว่าซอมบี้จะลงไพ่ซอมบี้หรือไม่)
- **แต้มน้อยกว่า**: ถูกแพร่เชื้อกลายเป็นซอมบี้

#### 💉 ไพ่วัคซีน
- ใช้รักษาซอมบี้กลับเป็นมนุษย์
- **ห้ามใช้กับตัวเอง** (ตามกติกา)
- ลบไพ่ซอมบี้ทั้งหมดของผู้ถูกรักษา

### เงื่อนไขการจบเกม
เกมจะจบเมื่อ:
- ทุกคนกลายเป็นซอมบี้ (ซอมบี้ชนะ)
- ซอมบี้ถูกกำจัดหมด (มนุษย์ชนะ)
- ผู้เล่นหมดไพ่ตัวเลข (ฝ่ายที่มีคนมากกว่าชนะ)

\`\`\`bash

npm install

# รันเซิร์ฟเวอร์
npm run dev
\`\`\`

## 🎮 วิธีใช้งาน

1. เปิดเบราว์เซอร์ไปที่ \`http://localhost:3000\`
2. กดปุ่ม "สร้างห้องใหม่" และใส่ชื่อของคุณ
3. คัดลอกรหัสห้องที่ได้รับ
4. ส่งรหัสห้องให้เพื่อนๆ ที่อยู่ใน Local Network เดียวกัน
5. เพื่อนเปิด \`http://<your-ip>:3000\` และเข้าร่วมห้องด้วยรหัส
6. เมื่อทุกคนพร้อม กด "พร้อมเล่น"
7. เริ่มเล่นเกม!

## 📝 หมายเหตุ

- ต้องเล่นผ่าน Local Network เดียวกัน (WiFi หรือ LAN เดียวกัน)
- แนะนำให้มีผู้เล่น 3-8 คนสำหรับประสบการณ์ที่ดีที่สุด
- ใช้เบราว์เซอร์สมัยใหม่ (Chrome, Firefox, Safari, Edge)
